## Supabase et SQL

Aucune modification directe ne doit être effectuée sur Supabase depuis ce projet.

Si une évolution de schéma, une table, une colonne, une policy RLS ou toute autre requête SQL est nécessaire, elle doit être ajoutée dans un fichier SQL ou une migration documentée dans ce dépôt, puis exécutée manuellement par le propriétaire du projet après vérification.

Avant toute exécution :

1. Lire et vérifier le script SQL concerné.
2. Faire une sauvegarde de la base si nécessaire.
3. Exécuter le script dans le SQL Editor Supabase ou via l’outil habituel du projet.
4. Vérifier les résultats et les policies RLS après exécution.

Les modifications de code peuvent être préparées ici, mais aucune migration et aucune requête SQL ne sera exécutée automatiquement sur Supabase.
